# AI Solutions Portfolio

Static portfolio site for all AI solutions. Hosted on GitHub Pages.

## Deploy to GitHub Pages

1. Create a new GitHub repo (e.g. `ai-portfolio`)
2. Push this folder:
   ```bash
   cd portfolio
   git init
   git add .
   git commit -m "Initial portfolio"
   git remote add origin https://github.com/YOUR_USERNAME/ai-portfolio.git
   git push -u origin main
   ```
3. Go to repo **Settings → Pages → Source → Deploy from branch → `main` / `/(root)`**
4. Your site will be live at `https://YOUR_USERNAME.github.io/ai-portfolio`

## Updating

- Replace `href="#"` links on solution cards with your live demo URLs or IPs
- Update GitHub repo URLs on each card to point to your actual repos
- For the 3 placeholder cards (Playmind AI, Virtual Cradle AI, Digital Cradle Twin), add real descriptions and tags when ready
